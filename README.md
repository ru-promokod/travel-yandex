## Как применить промокод

1. Выберите отель, билет или другой подходящий вариант поездки.
2. Перейдите к оформлению заказа.
3. Введите `ADM-ALL-1000` в поле для промокода до оплаты.
4. Убедитесь, что стоимость уменьшилась на 1 000 ₽.

## Почему промокод может не сработать

Код может не примениться из-за недостаточной суммы заказа, завершения акции, региональных ограничений или несовместимости с другим предложением. На часть бронирований промокоды и кешбэк могут распространяться по разным правилам.
